## 📖 项目简介

小语笔记是一款专注于英语词汇学习的 Web 应用，通过智能化的学习工具和科学的记忆方法，帮助用户高效掌握英语单词。平台支持响应式设计，可在 PC、平板和手机端无缝切换使用。

### 核心特色

- 🎯 **结构化记忆** - 科学的复习算法，基于艾宾浩斯遗忘曲线优化学习效果
- 📊 **数据可视化** - 生词日历、学习进度分析，让学习成果一目了然
- 🎮 **游戏化学习** - 听写、消消乐、卡片背单词等多种练习模式
- 🔄 **多端同步** - WebSocket 实时同步学习进度，随时随地无缝衔接
- 🤖 **智能录入** - API 自动匹配单词释义、音标，500词/日智能配额

## ✨ 核心功能

### 🔐 身份验证系统
- **注册方式**: 手机号 + 密码 + 邀请码
- **安全策略**: 邀请码强校验 + 行为风控（无短信验证码）
- **防刷机制**: IP/设备限流、蜜罐技术、防爆破保护
- **账户管理**: 多端同步、密码重置（客服渠道）

### 📚 单词库大厅
- **个人学习区**
  - 智能继续学习（上次学习进度自动恢复）
  - 错题本（错题统计与专项练习）
  - 生词日历（热力图展示每日新增生词）
  - 新建自定义词库

- **词库资源列表**
  - 分类筛选：全部 / 考试 / 场景 / 教材
  - 响应式网格布局
  - 书籍封面、标题、单词总量、描述
  - 学习状态标识（学习中 Badge）

### 📖 单词书详情页
- **智能筛选**
  - 主题筛选（下拉菜单 / 底部抽屉）
  - 场景筛选（二级联动）
  - 状态筛选：全部 / 未标注 / 认识 / 不认识 / 模糊
  - 排序：默认 / 随机打乱

- **单词列表**
  - 完整信息：单词、音标、释义、搭配、例句
  - Web Speech API 发音（支持单词/搭配/例句）
  - 中文显隐切换
  - 状态标记：认识(绿) / 模糊(黄) / 不认识(红)

- **核心逻辑**：内容局部化，状态全局化
  - 单词释义跟随单词书（同一词在不同书中释义不同）
  - 学习状态跟随用户全局（标记一处，处处同步）

### 🎮 练习系统

#### 听写模式 (Dictation)
- 自动播放音频（Web Speech API）
- 循环检测机制（未输入时每 2 秒重播）
- PC 端物理键盘 / Mobile 端软键盘
- 即时反馈：正确绿色边框 + "Ding" 音效，错误红色震动 + "Buzz" 音效
- 错误惩罚机制：显示正确拼写，2 秒倒计时后切题

#### 消消乐 (Match Game)
- 随机抽取 10 对卡片（英汉配对）
- 点击翻转 + 匹配消除
- 边界处理：< 3 词提示去学习更多，≥ 10 词随机抽取
- 成功匹配后单词状态更新为"认识"

#### 卡片背单词 (Flashcards)
- 点击翻转查看释义
- 手势操作：左滑(认识) / 右滑(不认识)
- 包含音标、发音按钮、搭配信息

### ✏️ 自定义词库编辑器
- **智能录入**: 批量输入英文单词，自动匹配释义、音标
- **配额限制**: 单用户每日 500 词智能识别
- **章节管理**: 新增、重命名章节
- **删除保护**: 3 次确认流程，防止误删
- **空状态引导**: 打造专属单词书

### 📅 生词日历与错题本
- **生词日历**
  - 热力图展示每日新增生词
  - 点击查看当日单词列表
  - 导出功能：图片 / Excel（支持隐藏中文自测）

- **错题本**
  - 数据源："不认识"或"模糊"状态的单词
  - 支持听写、消消乐练习
  - 空状态：奖杯插画 + "去背新单词"引导

### 🔧 后台管理
- **官方词库导入**: Excel 离线导入模式
- **字段标准**: Chapter / Word / Phonetic / Definition / Theme / Scene
- **自动构建**: 后端自动根据字段构建标签树

## 🎯 用户流程

```
1. 注册/登录
   └─ 输入手机号 + 密码 + 邀请码
   └─ 滑块拼图验证

2. 选择单词书
   └─ 浏览词库大厅（分类筛选）
   └─ 查看书籍详情（主题/场景筛选）

3. 学习单词
   └─ 浏览单词列表
   └─ 标记状态（认识/模糊/不认识）
   └─ 发音练习（Web Speech API）

4. 练习巩固
   └─ 听写模式（键盘输入 + 即时反馈）
   └─ 消消乐（游戏化配对）
   └─ 卡片背单词（翻转 + 手势操作）

5. 复习生词
   └─ 生词日历（查看历史记录）
   └─ 错题本（针对性练习）

6. 数据分析
   └─ 学习进度可视化
   └─ 多端同步（PC/Mobile/Pad）
```

## 📋 开发规范

### 代码规范
- 使用 TypeScript 编写
- 遵循 ESLint 规则
- 组件采用函数式组件 + Hooks

### 命名规范
- 组件：PascalCase（如 `WordList.tsx`）
- 工具函数：camelCase（如 `formatDate.ts`）
- 常量：UPPER_SNAKE_CASE（如 `API_BASE_URL`）
- 类型/接口：PascalCase（如 `User`, `Book`）

### Git 提交规范
```
feat: 新功能
fix: 修复 Bug
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试相关
chore: 构建/工具链更新
```

## 🎨 UI/UX 细节

### 骨架屏加载
- L1 大厅骨架屏展示时间 ≤ 1.5 秒

### 虚拟列表
- 单词列表单页数据 > 100 条时启用虚拟滚动

### 空状态处理
- 搜索无结果：放大镜插画 + "未找到相关内容" + "意见反馈"链接
- 错题本清空：奖杯插画 + "太棒了！你消灭了所有错题。"

### 交互反馈
- **正确**: 绿色边框 + "Ding" 音效
- **错误**: 红色边框 + 震动动画 + "Buzz" 音效
- **加载中**: 转圈动画 + 禁用交互
