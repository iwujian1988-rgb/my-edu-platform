## 🎨 功能详解

### 1. 设置系统（4个标签页）

#### 🎵 音效设置
- **单词发音**：自动朗读单词（可调节音量和倍速）
- **释义发音**：朗读中文释义
- **按键音**：打字时播放按键音效
- **效果音**：正确/错误提示音

#### ⚙️ 高级设置
- **章节乱序**：随机排序单词
- **显示前后单词**：显示上下文导航
- **忽略大小写**：输入时不区分大小写
- **允许选择文本**：支持鼠标文本选择
- **默写模式显示提示**：鼠标hover显示答案

#### 🖥️ 显示设置
- **外语字体大小**：20-100px 可调
- **中文字体大小**：12-50px 可调
- **深色模式**：切换深色/浅色主题
- **重置字体**：恢复默认字体设置

#### 💾 数据设置
- **数据导出**：导出学习数据为JSON文件
- **数据导入**：从备份文件恢复数据
- **重置进度**：清除所有学习数据

### 2. 工具栏按钮

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 🔊 音量 | 单词发音开关 | - |
| 👁️ 默写 | 默写模式切换 | Ctrl+V |
| 📝 释义 | 显示释义切换 | Ctrl+Shift+V |
| 🌙 深色 | 深色模式切换 | - |
| ⚙️ 设置 | 打开设置面板 | - |

### 3. 底部统计面板

实时显示5项关键指标：
- **时间**：学习时长（MM:SS格式）
- **输入数**：累计输入字符数
- **WPM**：每分钟单词数
- **正确数**：正确输入的字符数
- **正确率**：准确率百分比

## 🎯 使用流程

### 开始练习

1. **选择词库**：从顶部下拉菜单选择词典
2. **开始打字**：按任意键或 Enter 开始
3. **查看统计**：底部面板实时显示进度
4. **调整设置**：点击工具栏按钮调整功能

### 自定义设置

1. **打开设置**：点击 ⚙️ 设置按钮
2. **选择标签**：点击音效/高级/显示/数据标签
3. **调整选项**：使用开关和滑块调整
4. **保存设置**：设置自动保存到本地存储

### 数据管理

1. **导出数据**：设置 → 数据 → 点击"导出数据"
2. **备份文件**：保存到安全位置
3. **恢复数据**：设置 → 数据 → 点击"导入数据"

## 🐛 常见问题

### Q: 页面显示空白？
**A**: 检查控制台错误，确保 `data-loader.ts` 正确导入 JSON 文件。

### Q: 快捷键不工作？
**A**: 确保焦点在页面上（点击页面任意位置），没有其他应用占用快捷键。

### Q: 设置没有保存？
**A**: 设置会自动保存到浏览器的 LocalStorage。清除浏览器数据会导致设置丢失。

### Q: 深色模式文字看不清？
**A**: 某些元素可能需要调整颜色，请在设置中调整字体大小。
