# 职场英语单期质量验收表

版本 1.0，适用于第 001 期之后的每一期。生成器和结构校验只负责发现格式、字段和文本错配；每一期仍须由编辑按本表阅读并把 9 项分数写入 `lesson.review.scores`，才能改成 `approved` 并进入公开目录。

## 发布前检查

每项按 0–2 分记录：0 = 不合格；1 = 能用但需要修改；2 = 清楚、准确，可直接发布。

| 检查项 | 满分标准 |
|---|---|
| 用户任务 | 首屏就看懂本期要解决的工作问题，任务只要求一项明确的英语输出。 |
| 题目与答案 | 参考答案直接回应题目；后续范例与答案使用同一表达目标。如措辞更具体，只用一句话说明对应关系。 |
| 迁移练习 | 结尾任务换到一个相邻但不同的工作情境；沿用本期表达目标，答案要回应新情境，不能照抄开头题或参考答案。 |
| 核心表达 | 只选本场景最值得记住的表达；三条表达各自承担不同用途，词卡标题、中文释义、例句和练习互相对应。每条都在本期练习或最终输出中实际出现；较弱相关的原文词放入折叠选学区或删除。 |
| 原文 | 原文准确、完整可读；明确标出本期必读段落，其他部分可选读。译文与原文逐段对应。 |
| 学习顺序 | 先独立作答，再从原文发现表达，接着看示范、练习、迁移到新场景，最后自测和复习。每一步的作用对首次使用者清楚。 |
| 练习 | 填空、听写、语气判断和翻译都检查本期目标表达；错误反馈指出具体差异并给出修正线索。听写可直接用准确原文核对；只有存在具体发音或辨音要点时才添加提示，不用通用句填充。 |
| 英语质量 | 参考表达自然、语法正确、符合工作语境；不是把中文逐字翻成英文。场景和角色与公司真实材料明确区分。 |
| 音频 | 逐条对照文本检查漏词、错词、截断和停顿；至少抽听原文、场景和听写片段，确认语速适合跟读。 |
| 页面与文案 | 标题不重复，下一步操作醒目；没有制作过程、教学设计自证、重复原则或无助于完成任务的说明。选学词注释解释词义与用法，不说明编辑为何把它列为选学。 |

总分至少 16/18，且“用户任务、题目与答案、核心表达、原文、练习、英语质量、音频”各项必须为 2 分。任何一项未达标，先修改再复核。发布检查会拦截缺分、低于门槛或关键项未满分的课。记录逐项分数、改动和复核人，不以自动校验代替人工判断。自动校验同时拦截与开头完全相同的结尾题目或答案；编辑仍须确认迁移题与本期目标表达相关。

## 逐篇走查顺序

1. 先不读说明，打开页面，检查首次用户能否在几秒内说出本期学什么、现在该做什么。
2. 只看题目和核心答案，确认答案直接回答题目；对照后续示范，确认同一工作问题、同一目标表达。
3. 只看核心词卡和所有例句，逐条问“用户今天会在工作里用这句话吗”；确认词卡标题、释义和例句说的是同一件事，三条核心表达各有用途，并在完形、听写、翻译或最终输出中练到；不合适就改成选学或删除。
4. 对照来源逐段检查全文、重点段、译文、公司归属和授权记录；不把迁移练习写成企业真实案例。
5. 实际完成填空、听写、选择和迁移写作，核对正确答案、错误反馈、计数和复习记录；逐条抽听音频，确认与文本一致且没有截断。
6. 手机和桌面各看一遍；检查标题层级、留白、点击反馈、音频首屏可操作性和保存状态。

## 批次节奏

每批制作 5 期：先完成原文核对和内容草稿，再逐期完成页面与音频，最后逐期按表复核。每期通过才标为 `approved`；批次摘要只报告已通过数量和阻塞项，不能用 100 篇“有草稿”来表示 100 篇完成。
