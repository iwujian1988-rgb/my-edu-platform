# 名企职场英语｜开发交接

## 服务与页面

| 位置 | 职责 |
|---|---|
| `src/app/work-english/` | 独立目录、搜索、状态筛选、登录直达和卡片交互 |
| `src/app/work-english/lessons/[id]/route.ts` | 验证账号/套餐后生成完整课程文档；将账号学习状态安全注入页面 |
| `src/app/work-english/lessons/[id]/media/[file]/route.ts` | 每次请求校验权限，支持音频 Range；禁止缓存付费媒体 |
| `src/app/api/work-english/progress/[id]/route.ts` | 账号级读写与乐观并发控制；请求体和来源校验 |
| `src/lib/work-english/` | 目录元数据、套餐规则、进度模型与共享服务 |
| `src/content/work-english/001/` | 第 001 期私有 HTML、脚本、内容数据、音频和插图 |
| `src/content/work-english/cloud-sync.js` | 自动保存、失败重试、冲突保护、离开提醒 |
| `src/lib/auth-return-path.ts` / `request-origin.ts` | 安全站内跳转及反向代理外部地址解析 |

课程以受保护的 Next Route Handler 返回整页文档，目的是完整保留已确认的学习 UI。它不是公开静态 HTML 或未受保护的 iframe。文本、答案、音频放在服务端内容目录；只有课程目录元数据和封面公开。当前交付没有复制一套账号系统。

## 数据库

迁移：`supabase/migrations/2026101501_work_english.sql` 和 `2026101502_work_english_registration_flow.sql`，均已在现有数据库执行。第二个迁移停用额外的客户端兑换流程，并支持后台创建的不同名企英语套餐。

- 套餐 ID：`741aee1a-1fd4-49c4-bf69-44900d18b301`。
- 功能标识：`work_english`。访问校验要求持有一个有效且包含此功能的后台套餐；不能只修改 users.feature_permissions 获权，不再写死单一套餐 ID。
- `work_english_progress`：主键 `(user_id, lesson_id, lesson_version)`；`state` 为受约束 JSONB；`revision` 用于并发保护。RLS 同时要求本人和有效套餐。
- `work_english_activation_limits`：已退役，保留历史记录，客户端不可访问。
- `redeem_work_english_code`：已撤销 PUBLIC/anon/authenticated 执行权限，前台 API 已删除。赋权统一走原有注册时调用的 `use_invitation_code`。
- `work_english_has_access`：供进度表 RLS 使用。
- 用户表新增保护 trigger：普通客户端不能自行加入本付费套餐，也不能修改已有本套餐用户的期限/封禁字段。受信任的服务端和数据库函数仍能授予权益。

进度 API 从登录会话取得 user_id，不接受客户端指定用户；草稿在 HTML 中作为 JSON 数据转义；自动保存不使用共享 localStorage。更新时匹配 revision，冲突返回 409，禁止静默覆盖。失败时保留当前页面内容，允许导出与重试。

## 套餐和注册码入口

1. 后台套餐勾选“名企职场英语”（`work_english`），按原有规则设置期限。
2. 邀请码管理选择套餐，批量生成 N 个注册码。发码接口要求管理员发码权限。
3. 复制和 Excel 导出的注册链接都带 `code` 与 `redirect=/work-english`。用户只收到注册码时，在普通注册页填写也能依套餐返回本产品。
4. 注册由原有 `use_invitation_code` 赋权；`signup` 返回套餐落地页，注册表单直接采用。原有视频/小说跳转保留。
5. 老用户从产品入口登录即可回到学习库；不提供前台兑换。学习内容、媒体和进度仍检查有效套餐。
