# 职场英语 101–200 生产台账

新增系列编号：101–200。001–100 保持原目录与状态不变。

## 单篇完成条件

- 来源页来自公司官网、员工手册、官方培训材料或公开的公司工作指南；标清真实材料类型，不把公司博客写成“内部文件”。
- 保存来源快照与原文段落；来源标题、作者/日期（若有）、链接和段落内容能对应核验。逐段中文译文由编辑检查。
- 学习任务从真实工作困境切入；开头题目、参考答案、词汇短语、语法讲解、跟读/听辨、练习和迁移题指向同一个能力目标。
- 参考答案直接回答开头题目；核心表达优先是工作中能立即使用的短语，不为凑数加词。
- 用户页不放制作备注、质量术语、内部审核话术或多余免责声明。
- 音频必须能点击播放并与当前文字一致；新音频只用项目现有免费生成流程，不调用付费 API 或克隆声线。不得在未听检前宣称自然。
- 单篇达到内容质量表 18/20，关键项全 2 分；完成页面、账号/进度和真实线上检查后才进入发布清单。

## 选材方向：读大公司的业务做法，练能用的职场英语

- 用户购买的是能用于工作的英语和看懂大公司如何推进业务，不是单纯阅读员工守则。员工手册、行为准则类来源只作少量补充，主要用于边界沟通、客户隐私、求助等真实高频场景。
- 101–200 最终来源中，至少 70 篇应来自具体业务实践：客户需求访谈与销售、项目推进与复盘、产品和营销决策、业务汇报与数据、客户服务与运营、跨团队协作和管理沟通。
- 员工行为准则、合规政策、福利与一般文化介绍合计不超过 15 篇；不再新增仅讲抽象价值观或规则、无法转成实际业务对话的来源。
- 每篇来源都要落到一个工作结果：问清需求、争取资源、说明方案、回应异议、同步风险、解释数据、确定下一步等。学完后应能复用至少 3 条自然表达。
- 如来源是公开博客、案例或指南，就如实标成公开材料；不包装成“内部资料”。“大公司怎么做事”来自真实业务内容和具体做法，不靠伪造内部感。
- 101–120 首批虽已完成草稿，进入新增课制作前要复查来源类型与业务场景占比；仅手册阅读或主题雷同的课应替换或重做，不因已写完而保留。
