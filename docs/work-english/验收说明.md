## 建议验收顺序

1. 从产品入口用私有说明里的测试账号登录，确认直接进入名企英语。新用户可以使用私有说明里的未使用注册码完成注册，验证自动赋权和跳转。
2. 打开第 001 期，首先看到原文；切换中文对照和彩色批注，检查你要的学习资料感。
3. 播放原文和听写音频，试试倍速、循环与暂停；收藏一个单词。
4. 做一遍填空和听写，写下自己的反馈，再查看解析与前后对照。
5. 刷新页面查看记录，标记完成后回到学习库；手机或另一浏览器登录同账号也能继续。

## 交付边界

- 当前实际内容为 1 期，目录如实显示 1 期。300 期铺底、日更内容和内容制作 Skill 属于你指定的下一阶段，本次没有假装完成。
- 没有新增付费结算系统；使用原有“后台创建套餐 → 批量生成注册码 → 用户注册自动赋权”的交付方式。前台激活界面/API 已移除，对应数据库兑换 RPC 已撤销客户端权限，保留历史数据。
- 套餐有效期暂按现有平台设置为 365 天，售价未设置。现有平台只有用户级的 `permission_expires_at`，不是逐套餐独立到期；新模块沿用现有注册赋权规则。若以后需要不同套餐分别到期，需要统一升级平台权益模型。
- 测试使用专用账号和测试邀请码，没有用实际学员的数据做写入测试。验收账号信息仅保存在 Git 忽略的本地文件。
- 本次没有提交、推送或部署整仓既有改动。上线前应只选择本模块及必要修复，避免把工作区其他尚未验收的改动一起发布。

## 本次附带修复

- 登录 middleware 原来忽略返回地址，导致已登录用户被送回首页；现在保留安全的站内返回路径和刷新后的 cookies。
- 旧法语词典把 Node 文件加载器带进浏览器打包，导致整站生产构建失败；将服务端分支保留为 Node 原生动态导入，浏览器仍走原有 JSON 请求，并做了双分支回归测试。
- 新模块涉及的 HTTPS 代理来源校验及跳转已按外部 Host/协议处理。
