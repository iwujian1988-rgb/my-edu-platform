## 一、功能清单

### 1. 视频大厅 `/videos`

| 功能 | 说明 |

| 进度条 | 每个视频卡片显示观看进度 |

### 2. 视频学习核心 `/videos/[id]`

| 功能 | 说明 |
|------|------|
| **四模式切换** | 字幕模式 / 跟读模式 / 听写模式 / 知识点模式 |
| 双语字幕 | 三种显示：双语 / 仅原文 / 仅中文 |
| 高亮标注 | 字幕中自动标注词汇(蓝)、短语(绿)、地道表达(紫) |
| 点击查词 | 点击高亮词弹出详细卡片（音标、词性、释义、近义词、例句） |
| 段落复读 | 精确到单句的播放控制 |
| 变速播放 | 0.5x ~ 1.25x |
| 进度自动保存 | 每 5 秒自动保存 + 离开页面 sendBeacon 保底 |
| 字幕导出 | PDF 和 Word 格式导出 |

### 3. 跟读模式（Speak Tab）

| 功能 | 说明 |
|------|------|

| 波形对比 | 原声 vs 录音 双波形可视化 |
| 自动滚动 | 录音面板跟随视频时间轴滚动 |

### 4. 听写模式（Write Tab）

### 5. 知识点系统（Learn Tab）

| 功能 | 说明 |
|------|------|
| 词汇卡片 | 音标、词性、性别(法语)、CEFR 等级、搭配、例句 |

| 发音技巧 | 音标符号 + 示例词 + 练习指导 |

| 三状态标记 | 不认识(红) / 学习中(黄) / 已掌握(绿) |

## 二、核心卖点

| 卖点 | 对应功能 | 差异化价值 |
|------|----------|-----------|
| **看视频 ≠ 刷视频** | 四模式 + 进度追踪 | 每个「看过的视频」都变成「学过的课」 |
| **一个视频，五个维度** | 词汇/短语/表达/语法/发音 | 不是只背单词，而是立体理解语言 |
| **字幕即课本** | 高亮 + 点击查词 + 导出 | 字幕不再是辅助，而是学习的主材料 |
| **听得出、说得出、写得出** | 跟读录音 + 波形对比 + 听写填空 | 三感联动，不止"看得懂" |
| **学了不会忘** | SM-2 闪卡 + 三状态标记 | 间隔重复把短期记忆变成长期记忆 |
| **词汇网络** | 关联词群可视化 | 不是孤岛式背词，而是网状生长 |
| **零感知 PIP** | DOM 复用画中画 | 手机上边看边学，零切换成本 |
| **8 种语言一套方法** | 多语言架构 | 同一个学习引擎，切换语言零门槛 |

## 三、「五感学习法」—— 用户学习路径

> **核心理念**：不卖功能，卖方法。用户不是在用"4 个 tab"，而是在走一个有节奏的学习闭环。
>
> 看一眼 → 点一下 → 说一遍 → 写一次 → 记住了 —— 五个动作对应五种感官，每一步都是用户自然想做的事。

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Step 1: IMMERSE (沉浸)                                    │
│   ────────────────────────                                  │
│   看 → 听 → 感受                                            │
│   · 双语字幕，正常语速看完一遍                                │
│   · 享受内容，不需要暂停                                     │
│   · 系统后台自动标记进度                                     │
│                                                             │
│          ↓                                                  │
│                                                             │
│   Step 2: SPOT (捕捉)                                       │
│   ────────────────────────                                  │
│   字幕高亮 → 点击查词 → 建立认知                             │
│   · 第二遍，开启双语字幕                                     │
│   · 蓝色词汇 / 绿色短语 / 紫色表达，点击即出卡片              │
│   · 标记为"不认识"(红) 或 "学习中"(黄)                       │
│                                                             │
│          ↓                                                  │
│                                                             │
│   Step 3: SHADOW (跟读)                                     │
│   ────────────────────────                                  │
│   听原声 → 录音 → 波形对比                                   │
│   · 切到「跟读」tab                                         │
│   · 逐句听原声，录下自己的发音                                │
│   · 双波形对比：你的节奏和原声差多远？                        │
│   · 不满意？重来，直到波形接近                                │
│                                                             │
│          ↓                                                  │
│                                                             │
│   Step 4: WRITE (听写)                                      │
│   ────────────────────────                                  │
│   初级提示 → 中级挑战 → 高级裸听                             │
│   · 切到「听写」tab                                         │
│   · 从初级开始（首字母提示）                                  │
│   · 逐步升级到高级（无任何提示）                               │
│   · 正确率 80% 以上？这一课你真的"会了"                      │
│                                                             │
│          ↓                                                  │
│                                                             │
│   Step 5: OWN (内化)                                        │
│   ────────────────────────                                  │
│   知识点总览 → 闪卡复习 → 词汇网络生长                       │
│   · 打开「知识点」tab，系统回顾这课的所有收获                  │
│   · 不认识→学习中→已掌握，三色追踪掌握度                      │
│   · 第二天：闪卡复习提醒，SM-2 安排需要巩固的词               │
│   · 一周后：词汇网络越来越密，关联词自动串联                   │
│                                                             │
│          ↺ 回到 Step 1，打开下一个视频                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 用户旅程叙事

> **Day 1 — 初次打开**
> 你选了一个法语初级视频。第一遍，你只是看——画面、情节、语调。字幕帮你理解大意，不需要暂停。这是 **IMMERSE**。
>
> **Day 1 — 第二遍**
> 你注意到字幕里有些词是蓝色、绿色的。你点了一下 "bonjour"——弹出卡片告诉你发音、词性、例句。你标记为"不认识"。这是 **SPOT**。
>
> **Day 1 — 跟读练习**
> 你切到跟读模式，听到一句 "Comment allez-vous?"，录下自己的版本。波形对比显示你的节奏偏快。再来一次。这是 **SHADOW**。
>
> **Day 1 — 听写挑战**
> 你切到听写，选了中级难度。系统给你首尾字母提示，你填了 8 个对了 7 个。那个写错的是 "allez"——记住了。这是 **WRITE**。
>
> **Day 2 — 闪卡复习**
> 手机弹出提醒：有 5 张卡片需要复习。你滑了滑，"bonjour" 已经记住了，"allez" 还需要再来。这是 **OWN**。
>
> **Day 7 — 词汇网络**
> 你打开知识点页，看到你学了 23 个词，它们之间有 12 条关联线。"bonjour" 连着 "salut"，连着 "bonsoir"。这不是孤立的单词表，这是你的语言网络。
>
> **Day 30 — 回看日历**
> 学习日历上，30 天里 22 天有记录。你不是在"打卡"，你是在**生活在这个语言里**。

## 四、功能 → 学习法映射

```
功能堆砌视角             →    学习法视角
──────────────────────────────────────────────
视频播放                →    第一步：沉浸，享受内容
字幕高亮 + 查词         →    第二步：捕捉，建立第一印象
跟读 + 录音 + 波形      →    第三步：跟读，肌肉记忆
听写填空                →    第四步：听写，验证输出
知识点 + 闪卡 + 网络    →    第五步：内化，长期记忆
```

**关键洞察**：产品已经具备完整学习闭环的所有拼图。缺的不是功能，而是**用一条叙事线把它们串起来**，让用户感受到"我在按照一个方法学习"，而不是"我在用一堆功能"。

## 五、技术架构概览

| 维度 | 技术选型 |
|------|----------|
| 框架 | Next.js App Router（Server Components + Client Components） |
| 数据层 | Supabase（服务端直查，并行预取） |
| 状态管理 | SWR（远程数据）+ Zustand（字典缓存）+ React State（UI 状态） |
| 样式 | Tailwind CSS，Neo-brutalism 设计语言（`#B4F416` 主色调） |
| 音频 | Web Audio API（波形）+ 后端 TTS（有道主 + 百度备）+ SpeechSynthesis 降级 |
| 间隔重复 | SM-2 算法 |
| PIP | DOM reparenting（`appendChild` 复用 `<video>` 元素，零缓冲） |
| 上传 | 阿里云 OSS STS 直传，分片 > 10MB，3 次重试 |
