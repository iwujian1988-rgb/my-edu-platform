| language_data.fr.gender | m 或 f | 维基词典 > Lexique > AI判断 |
| part_of_speech | noun/verb/adj/adv等 | 维基词典 > AI判断 |

## 3. AI翻译质量保障措施

### 3.1 核心原则
```
⚠️ 绝对禁止：
1. 编造不存在的释义（幻觉）
2. 添加原释义没有的信息
3. 翻译时丢失关键信息（如阴阳性）
4. 输出格式不规范
```

### 3.2 质量保障机制

#### A. 结构化输入
```json
{
  "word": "parole",
  "pos": "noun",
  "gender": "f",
  "english_gloss": "speech, language (the faculty of using spoken language...)"
}
```

#### B. 严格Prompt模板
```
你是专业的法语-中文词典编辑。请将以下法语词的英文释义翻译成中文。

【输入信息】
- 词: {word}
- 词性: {pos}
- 阴阳性: {gender}
- 英文释义: {english_gloss}

【输出要求】
1. 只输出中文释义，不要任何解释或额外文字
2. 释义要简洁，一般不超过20个汉字
3. 如果是名词，释义后不要加(m)或(f)，阴阳性会单独存储
4. 不要编造例句
5. 不要添加英文释义中没有的含义
6. 保持专业性，使用标准术语

【输出格式】
直接输出中文释义字符串，例如：言语，说话能力
```

#### C. 自动验证机制
```javascript
function validateTranslation(input, output) {
  const errors = [];

  // 1. 长度检查
  if (output.length > 50) {
    errors.push('释义过长，可能包含多余内容');
  }
  if (output.length < 2) {
    errors.push('释义过短');
  }

  // 2. 格式检查
  if (output.includes('(m)') || output.includes('(f)')) {
    errors.push('释义不应包含阴阳性标记');
  }

  // 3. 幻觉检查
  const hallucinationPatterns = [
    /例如[:：]/,        // 不应有"例如"
    /\d+\.\s/,          // 不应有编号列表
    /常见用法/,          // 不应有用法说明
  ];
  for (const pattern of hallucinationPatterns) {
    if (pattern.test(output)) {
      errors.push(`可能包含幻觉内容: ${pattern}`);
    }
  }

  // 4. 反向翻译验证（可选，成本较高）
  // 将中文翻译回英文，检查是否与原英文释义相关

  return errors;
}
```

#### D. 批量处理 + 抽样审核
```
Step 1: 批量翻译 9,453 个词
Step 2: 自动验证，标记有问题的翻译
Step 3: 随机抽取 5% (~470词) 人工审核
Step 4: 如果错误率 > 5%，调整prompt后重新翻译
Step 5: 最终确认
```

### 3.3 分级处理策略

| 风险等级 | 条件 | 处理方式 |
|----------|------|----------|
| 低风险 | 常用词 + 清晰英文释义 | 直接AI翻译 |
| 中风险 | 专业术语 + 长释义 | AI翻译 + 人工复核 |
| 高风险 | 多义词 + 歧义释义 | 人工处理 |

## 4. 工作流程

### Phase 1: 更新有中文释义的词 (12,871词)
```
来源: 中文维基词典
操作: 直接更新数据库
验证: 自动检查格式
风险: 无AI，无幻觉风险
```

### Phase 2: AI翻译英文释义 (9,453词)
```
来源: 英文维基词典英文释义
操作: 批量AI翻译
验证:
  1. 自动格式检查
  2. 抽样人工审核
  3. 问题词标记
风险: 需要严格监控
```

### Phase 3: 纯AI翻译 (7词)
```
来源: 无词典数据
操作: AI根据词本身翻译
验证: 必须人工审核
风险: 最高，需谨慎
```

### Phase 4: 最终验证
```
1. 检查所有词都有释义
2. 检查名词都有阴阳性
3. 随机抽样100词人工审核
4. 生成质量报告
```

## 5. 验收标准

### 5.1 必须满足
- [ ] 100% 词汇有中文释义
- [ ] 0 个释义包含"(m)"/"(f)"标记
- [ ] 0 个释义是"的变位"等低质量内容
- [ ] 名词阴阳性覆盖率 > 90%

### 5.2 质量指标
- [ ] AI翻译抽样错误率 < 5%
- [ ] 释义长度平均值在 5-20 字之间
- [ ] 无明显幻觉（编造例句、添加无关信息）

## 6. 回滚机制

如果发现大规模质量问题：
1. 立即停止更新
2. 使用数据库备份回滚
3. 分析问题原因
4. 调整策略后重新执行
