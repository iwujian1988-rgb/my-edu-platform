# 视频学习模块改版

## 已实现
- 首页分类快速筛选；卡片封面加大、去描述；移除视频区 class 入口。
- 学习指南 `/videos/guide`；第一次进入首页弹层，关闭后当前浏览器不重复提醒。
- 详情默认沉浸式；视频上直接遮挡字幕；精听从头重播；跟读区直接显示小视频。
- 完成学习保存成功后返回首页，保存失败显示重试；我的新增学习记录。
- 免费领取文案统一为「0元免费领」。

## 后续内容标准
- 新增、重编的法语选择题：题干、全部选项为法语；解析可以中文。已有题目不批量修改。
- 上传校验防止中文题干/选项入库；自动校验不能可靠区分英语和法语，发布前仍须确认法语自然、答案唯一且有原文依据。
- 新下载默认优先 1080p，最低尽量 720p；来源不足时保留真实清晰度并更换片源，不用放大冒充高清。
- 高清下载入口：`node scripts/download-video-hd.mjs <URL> <目录>`，依赖 yt-dlp、ffmpeg；保留信息 JSON 以核对真实尺寸。原有低清视频不自动重下。
- 上传后抽检桌面和手机的字幕清晰度、播放速度与首屏加载。素材生成器在另一项目，本改版不自动重写其存量资料。

## 学习包装
选合适内容 → 盲听抓大意 → 对照字幕精听 → 原声跟读 → 练习确认理解 → 完成留记录 → 次日复习。
时间安排为参考：轻量约 10 分钟，完整约 20 分钟，按视频长度调整。
