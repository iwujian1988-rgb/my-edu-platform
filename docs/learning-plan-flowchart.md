# 学习计划模块 - 完整流程图

## 1. 创建学习计划流程

```
用户进入单词书详情页
        │
        ▼
   点击"开始学习计划"
        │
        ▼
┌───────────────────────┐
│ 学习计划设置页         │
│ - 显示单词书信息       │
│ - 每天新学单词（默认20）│
│ - 每天最多学习（默认50）│
│ - 预计完成天数         │
└───────────────────────┘
        │
        ▼
   用户调整参数
        │
        ├─→ 每天新学：10-100个（-5/+5调整）
        ├─→ 每天最多：≥ 新学数量（-10/+10调整）
        └─→ 实时计算预计天数
        │
        ▼
┌──────────────────────────────┐
│ 预计天数计算                  │
│                              │
│ 理想天数 = 总词数 ÷ 每天新学   │
│ 实际天数 = 理想天数 × 1.5     │
└──────────────────────────────┘
        │
        ▼
   点击"开始学习计划"
        │
        ├─→ ❌ 如果 最多 < 新学 → 按钮置灰
        └─→ ✅ 如果 最多 ≥ 新学 → 继续
        │
        ▼
┌──────────────────────────────┐
│ 数据库操作                    │
│                              │
│ INSERT INTO learning_plans   │
│ - user_id                    │
│ - book_id                    │
│ - daily_new_words            │
│ - daily_max_words            │
│ - total_words                │
│ - start_date = 今天          │
│ - status = 'active'          │
└──────────────────────────────┘
        │
        ▼
   跳转到今日任务页
```

## 2. 每日任务生成流程

```
用户打开今日任务页
        │
        ▼
┌──────────────────────────────┐
│ 检查今日任务是否已生成        │
│                              │
│ SELECT * FROM daily_tasks    │
│ WHERE task_date = 今天       │
└──────────────────────────────┘
        │
        ├─→ ✅ 已存在 → 直接显示
        │
        └─→ ❌ 不存在 → 生成新任务
                │
                ▼
┌──────────────────────────────┐
│ Step 1: 查询到期复习词       │
│                              │
│ SELECT * FROM review_schedule│
│ WHERE next_review_date <= 今天│
│ AND user_id = xxx            │
│ AND book_id = xxx            │
└──────────────────────────────┘
        │
        ▼
   到期复习词列表 (例如：8个)
        │
        ▼
┌──────────────────────────────┐
│ Step 2: 计算新学词数量       │
│                              │
│ 剩余名额 = daily_max - review_count│
│ 新学数量 = MIN(daily_new, 剩余名额)│
│                              │
│ 示例：                       │
│ - daily_max = 50             │
│ - review_count = 8           │
│ - 剩余名额 = 42              │
│ - daily_new = 20             │
│ - 新学数量 = MIN(20, 42) = 20│
└──────────────────────────────┘
        │
        ▼
┌──────────────────────────────┐
│ Step 3: 获取新学词           │
│                              │
│ SELECT * FROM words          │
│ WHERE id NOT IN              │
│  (已学过的单词ID)            │
│ ORDER BY random()            │
│ LIMIT 新学数量               │
└──────────────────────────────┘
        │
        ▼
   新学词列表 (例如：20个)
        │
        ▼
┌──────────────────────────────┐
│ Step 4: 创建今日任务记录     │
│                              │
│ INSERT INTO daily_tasks      │
│ - task_date = 今天           │
│ - plan_day = 第几天          │
│ - review_words = [8个ID]     │
│ - new_words = [20个ID]       │
│ - total_words = 28           │
│ - completed_words = []       │
│ - all_completed = false      │
└──────────────────────────────┘
        │
        ▼
   显示今日任务
```

## 4. 复习间隔计算流程

```
用户标记单词为"认识"
        │
        ▼
┌──────────────────────────────┐
│ 查询当前复习次数             │
│                              │
│ SELECT review_count          │
│ FROM review_schedule         │
│ WHERE word_id = xxx          │
└──────────────────────────────┘
        │
        ▼
   当前复习次数 (0, 1, 2, 3+)
        │
        ▼
┌──────────────────────────────┐
│ 计算下次复习间隔             │
│                              │
│ review_count = 0 → 7天       │
│ review_count = 1 → 7天       │
│ review_count = 2 → 15天      │
│ review_count = 3 → 30天      │
│ review_count = 4+ → 30天     │
└──────────────────────────────┘
        │
        ▼
┌──────────────────────────────┐
│ 更新复习计划                 │
│                              │
│ UPDATE review_schedule       │
│ SET                          │
│   review_count = count + 1   │
│   next_review_date =         │
│     今天 + 间隔天数          │
│   interval_days = 间隔天数   │
└──────────────────────────────┘
        │
        ▼
   完成

───────
如果不认识：
        │
        ▼
┌──────────────────────────────┐
│ 重置复习计划                 │
│                              │
│ UPDATE review_schedule       │
│ SET                          │
│   review_count = 0           │
│   next_review_date = 今天+7天│
│   interval_days = 7          │
└──────────────────────────────┘
        │
        ▼
   完成
```

## 5. 边界情况处理

### 5.1 复习词过多

```
查询到期复习词
        │
        ▼
   到期数量 (例如：50个)
        │
        ▼
┌──────────────────────────────┐
│ 检查是否超过每天上限         │
│                              │
│ IF 到期数量 > daily_max      │
└──────────────────────────────┘
        │
        ├─→ ❌ 不超过 → 全部加入
        │
        └─→ ✅ 超过 → 截断处理
                │
                ▼
┌──────────────────────────────┐
│ 按优先级排序                 │
│                              │
│ ORDER BY                     │
│   过期天数 DESC,             │
│   next_review_date ASC       │
└──────────────────────────────┘
                │
                ▼
┌──────────────────────────────┐
│ 只取前 N 个                  │
│                              │
│ 今日复习词 = 到期词          │
│   .LIMIT(daily_max)          │
│                              │
│ 剩余词留待后续               │
└──────────────────────────────┘
                │
                ▼
           显示提示
   "复习词较多，建议调整学习量"
```

### 5.2 单词书学完

```
生成今日任务
        │
        ▼
   获取新学词
        │
        ▼
┌──────────────────────────────┐
│ 检查是否还有未学单词         │
│                              │
│ IF 剩余未学词 = 0            │
└──────────────────────────────┘
        │
        ├─→ ✅ 有新词 → 正常流程
        │
        └─→ ❌ 无新词 → 检查复习词
                │
                ├─→ ✅ 有复习词 → 继续复习阶段
                │                │
                │                ▼
                │           显示提示：
                │           "所有新词已学完，
                │            现在是复习巩固阶段"
                │
                └─→ ❌ 无复习词 → 计划完成
                        │
                        ▼
                   显示弹窗：
                   "🎉 恭喜！所有单词已掌握"
                   选项：
                   - 换个单词书
                   - 复习全书
```

## 6. 数据流转关系图

```
learning_plans (学习计划)
        │
        ├── user_id
        ├── book_id
        ├── daily_new_words (每天新学数量)
        ├── daily_max_words (每天最多学习)
        └── total_words (总词数)
                │
                ▼ 生成任务
daily_task_records (每日任务)
        │
        ├── task_date (日期)
        ├── plan_day (第几天)
        ├── new_words (JSON: 新学词ID)
        ├── review_words (JSON: 复习词ID)
        ├── completed_words (JSON: 已完成ID)
        └── all_completed (是否全部完成)
                │
                ├─→ review_schedule (复习计划)
                │   ├── word_id
                │   ├── review_count (复习次数)
                │   ├── next_review_date (下次复习日期)
                │   └── interval_days (间隔天数)
                │
                └─→ word_status (单词状态)
                    ├── current_status (known/fuzzy/unknown)
                    └── updated_at
```

## 7. 完整用户旅程

```
Day 1: 创建计划
│
├─ 设置：新学20，最多50
├─ 生成任务：0复习 + 20新学 = 20词
└─ 学习完成：20个标记"认识"
    ↓
Day 2: 正常学习
│
├─ 生成任务：0复习 + 20新学 = 20词
└─ 学习完成：20个标记"认识"
    ↓
Day 7: 第一次复习
│
├─ 生成任务：20复习(Day1) + 20新学 = 40词
├─ 复习词：Day1学的20个（7天后到期）
└─ 学习完成：40个标记"认识"
    ↓
Day 8: 持续学习
│
├─ 生成任务：0复习 + 20新学 = 20词
└─ 学习完成：20个标记"认识"
    ↓
Day 15: 第二次复习
│
├─ 生成任务：40复习 + 20新学 = 60词
├─ 复习词：Day1的20个(15天) + Day7的20个(8天)
├─ 注意：60 > 50(daily_max)
└─ 截断处理：只取50个词学习
    ↓
Day 30+: 继续循环...
│
├─ 新学词逐渐减少
├─ 复习词逐渐增多
└─ 最终：只剩复习词
```
