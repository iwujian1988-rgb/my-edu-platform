Okay, anyways, we are going to try hot pot for the first time.

好啦，总之，我们要第一次尝试火锅。

地道表达 for the first time
第一次（做某事）
💡 用法说明
用于描述某人是第一次经历或尝试某事，常放在句末。
I'm eating sushi for the first time.
我第一次吃寿司。
She traveled abroad for the first time last year.
她去年第一次出国旅行。
00:08

And I was like, I'm craving this for dinner.

我当时就想，我晚饭就想吃这个。

地道表达 be craving /ˈkreɪvɪŋ/
非常想吃、馋（某样东西）
💡 用法说明
比 "I want" 更有「馋到了」的身体感，特别适合说宵夜、路过餐厅时突然被勾起的食欲。
I'm craving noodles tonight.
我今晚特别想吃面。
She's been craving spicy food all day.
她一整天都特别想吃辣的。

短语 hot pot place
火锅店
💡 用法说明
"place" 在口语中常用来指代餐厅、商店等场所，比 restaurant 更口语化。
Let's go to that new pizza place.
我们去那家新开的披萨店吧。
00:22

It's literally right there, so we have to try it.

就在那里，所以我们必须试试。

单词 literally /ˈlɪtərəli/
简直；确实地；就在（某地）
💡 用法说明
口语中常用于强调，表示"真的"、"简直"，即使不是字面意思也可以用。
It's literally five minutes away.
真的就五分钟路程。
00:28

单词 broth /brɒθ/
（火锅/汤的）汤底；肉汤
💡 用法说明
指煮肉或蔬菜的清汤，在火锅语境中指汤底。
The broth is so flavorful!
汤底太有味了！
