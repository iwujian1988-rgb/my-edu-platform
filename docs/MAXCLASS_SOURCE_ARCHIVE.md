# MAXCLASS Source Archive

`MAXCLASS_V1_HANDOFF_2026-06-14/` is the original Vue source snapshot used as the migration reference for the Next.js MAXCLASS/parcours integration.

Status:
- Kept as an external archive for reference and audit.
- Not imported by the Next.js app at runtime.
- Not included in production deploys.
- The migrated runtime implementation lives in `src/app/parcours`, `src/components/maxclass`, `src/data`, and related server/access helpers.

The local source directory was archived outside this project before removal from the workspace root. Do not recommit the full archive directory unless intentionally creating a separate source snapshot or backup branch.
