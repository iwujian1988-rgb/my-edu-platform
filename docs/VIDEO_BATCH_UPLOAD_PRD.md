## 1. 需求概述

### 1.1 背景

视频学习模块需要支持批量上传视频内容，包括字幕 JSON 和学习材料 JSON，系统自动解析并生成：
- 视频记录
- 字幕数据
- 单词卡片（调用词典服务获取详情）
- 地道表达卡片
- 语法点数据
- 发音要点数据
- 词汇网络数据

### 1.2 目标用户

- **后台管理员**：批量上传视频内容
- **前端用户**：在视频播放页的"学习模块"中查看和操作学习卡片

### 1.3 核心价值

1. **提升运营效率**：一次上传多个视频，减少重复操作
2. **保证数据质量**：自动解析标准 JSON 格式，减少人工录入错误
3. **丰富学习内容**：支持语法点、发音要点、词汇网络等深度学习内容

### 2.3 字段含义说明

#### 字幕 JSON 字段

| 字段 | 含义 |
|------|------|
| `unit_info.unit_num` | 单元编号 |
| `unit_info.theme` | 单元主题/标题 |
| `unit_info.start_time` | 单元开始时间 |
| `unit_info.end_time` | 单元结束时间 |
| `unit_info.subtitle_count` | 字幕条数 |
| `subtitles[].index` | 字幕序号 |
| `subtitles[].start_time` | 字幕开始时间 |
| `subtitles[].end_time` | 字幕结束时间 |
| `subtitles[].french` | 法语原文 |
| `subtitles[].chinese` | 中文翻译 |

#### 学习材料 JSON 字段

| 字段 | 含义 |
|------|------|
| `unit_info.cefr_level` | 欧标等级（A1-C2） |
| `unit_info.duration_minutes` | 时长（分钟） |
| `language_analysis.vocabulary[]` | 单词列表 |
| `language_analysis.vocabulary[].french` | 法语单词 |
| `language_analysis.vocabulary[].part_of_speech` | 词性 |
| `language_analysis.vocabulary[].ipa` | 国际音标 |
| `language_analysis.vocabulary[].chinese` | 中文释义 |
| `language_analysis.vocabulary[].occurrence_count` | 出现次数 |
| `language_analysis.key_expressions[]` | 地道表达列表 |
| `language_analysis.key_expressions[].expression` | 表达结构 |
| `language_analysis.key_expressions[].chinese` | 中文含义 |
| `language_analysis.key_expressions[].grammar_usage` | 语法用法 |
| `language_analysis.key_expressions[].example` | 例句 |
| `deep_learning.grammar_points[]` | 语法点列表 |
| `deep_learning.pronunciation.key_sounds[]` | 发音要点 |
| `deep_learning.vocabulary_network` | 词汇网络 |
| `practice` | 练习题 |

## 3. 后台批量上传功能

### 3.1 入口位置

在视频管理列表页添加"批量上传"按钮：

```
[+ 新建视频]  [📤 批量上传]    🔍 搜索...     状态 ▼    语言 ▼
```

### 3.2 批量上传页面

- 默认显示 3 行视频输入行
- 每行包含：上传字幕 JSON、上传学习材料 JSON、视频播放地址输入框
- 底部"添加一行"按钮
- 最底部"保存全部"按钮

### 3.3 功能要求

1. **文件上传**
   - 支持 JSON 文件拖拽上传
   - 上传后自动解析并显示预览信息
   - 解析失败显示错误提示

2. **数据验证**
   - 必须同时上传字幕 JSON 和学习材料 JSON
   - 验证 JSON 格式是否正确
   - 验证必要字段是否存在

3. **处理流程**
   - 创建视频记录
   - 解析并存储字幕
   - 调用词典服务获取单词详情
   - 从字幕中匹配例句
   - 存储各类学习卡片

4. **进度显示**
   - 显示每个视频的处理状态
   - 显示整体上传进度
   - 部分失败时显示错误信息

### 5.9 交互说明

#### 单词卡片交互

| 操作 | 行为 |
|------|------|
| 点击 [📍] | 跳转到字幕中该单词首次出现的位置 |
| 点击 [❓ 不认识] | 标记为 `unknown`，卡片背景变红 |
| 点击 [🤔 模糊] | 标记为 `learning`，卡片背景变黄 |
| 点击 [✅ 认识] | 标记为 `known`，卡片背景变绿 |
| 点击 📺 例句 | 播放该例句的音频/跳转视频位置 |

#### 地道表达交互

| 操作 | 行为 |
|------|------|
| 点击 [▶ 播放这段] | 视频跳转到该例句位置并播放 |
| 点击 [📍] | 跳转到字幕位置 |
| 点击 [⭐] | 收藏到用户收藏夹 |
| 三态按钮 | 同单词卡片 |

#### 发音要点交互

| 操作 | 行为 |
|------|------|
| 点击 [▶ 播放] | 播放该单词的发音音频 |
| 点击 [🎤 跟读练习] | 进入录音跟读模式 |
