### 3.4 功能规则

#### 激活码验证

```typescript
// 激活码格式: 字母+数字，8-16位
// 示例: ABC123XY, LEARN2026

验证规则:
1. 长度: 8-16 字符
2. 格式: 大写字母 + 数字
3. 状态: unused
4. 过期时间: 未过期（如有）

错误提示:
- "激活码格式不正确"
- "激活码已使用"
- "激活码已过期"
- "激活码不存在"
```

#### 密码规则

```typescript
密码要求:
1. 长度: 8-20 字符
2. 必须包含: 字母 + 数字
3. 可选: 特殊字符

强度提示:
- 弱: 仅字母或仅数字
- 中: 字母 + 数字
- 强: 字母 + 数字 + 特殊字符
```
